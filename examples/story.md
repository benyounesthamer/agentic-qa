# User story: task list

As a registered user, I want to log in and manage a list of tasks.

Acceptance criteria:
1. Logging in with username `demo` and password `demo123` opens the task page.
2. Logging in with a wrong password shows an error message and stays on the login page.
3. Adding a task shows it in the list and increases the task counter by one.
4. An empty task cannot be added.
5. Deleting a task removes it from the list and decreases the task counter by one.
